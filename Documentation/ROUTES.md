# Route Catalogue

All routes are hash routes under `Application/` and require the demo sign-in in the UI. Data is local mock state.

| Route | Screen |
|---|---|
| `#/login` | Login |
| `#/dashboard` | Dashboard |
| `#/pos` | Point of sale |
| `#/sales` | Sales |
| `#/products` | Products |
| `#/inventory` | Inventory overview and movements |
| `#/customers` | Customer directory |
| `#/customers/statement` | Customer statement |
| `#/suppliers` | Supplier directory |
| `#/suppliers/statement` | Supplier statement |
| `#/purchases` | Purchase list |
| `#/purchases/new` | New purchase invoice |
| `#/purchases/receiving` | Goods receiving |
| `#/purchases/returns` | Purchase returns |
| `#/finance/cashboxes` | Cashboxes and balances |
| `#/finance/shifts` | Cashier shifts |
| `#/finance/payments` | Payments |
| `#/finance/expenses` | Expenses |
| `#/finance/custodies` | Employee custodies |
| `#/finance/balances` | Balance overview |
| `#/inventory/warehouses` | Warehouses |
| `#/inventory/transfers` | Warehouse transfers |
| `#/inventory/counts` | Stocktaking |
| `#/inventory/adjustments` | Inventory adjustments |
| `#/branches` | Branch list and detail drawer |
| `#/attendance` | Attendance and check-in |
| `#/attendance/shifts` | Shift definitions |
| `#/activity` | Activity log |
| `#/reports` | Reports |
| `#/users` | Users and demo roles |
| `#/admin` | Store administration |
| `#/settings` | Settings |

Purchase invoice details, branch details, and other record details open as drawers from their list screens, rather than separate parameterized routes.
